# State of Emergency

A *text adventure* made with... Pygame-ce. What was I thinking?

## Purpose

This is a personal project I plan to submit to Boot.Dev. I wanted to write a
game and I wanted to be more familiar with Pygame than then Asteroids project
had made me, so I lept back into surfaces, font rendering, and the whole mess
of fillng surfaces on every frame so that you can write over them afterward.

## Inspiration

- Björk Guðmundsdóttir. Specifically, ["Jóga"](https://www.youtube.com/watch?v=loB0kmz_0MM) from the *Homogenic* album.
- David Lynch
- Text adventure games like *The Hitchhiker's Guide to the Galaxy*
- *Undertale*
- Wanting to make a game since I was a boy.

## Install/run

This thing isn't even close to finished, but if you want to see the mess I have
made in action, use [uv](https://docs.astral.sh/uv/).

- Download and install uv.
- Download this repository.
- Navigate to the program's directory.
- Run `uv sync`.
- Run `uv run code/main.py`
